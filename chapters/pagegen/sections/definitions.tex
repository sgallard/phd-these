
\section{Introduction}
\label{sec:pagegen-challenge}

\subsection{Motivation}

While Chapter~\ref{chapter:template} focused on retrieving templates, an automated newspaper production workflow requires creating a layout from an entire array of unstructured web articles $\articleset = \{\articleobj{1}, \articleobj{2}, \dots, \articleobj{n}\}$ and a page canvas $\page$. This page generation step is precisely the central bottleneck identified in Chapter~\ref{chapter:context} and the main problem addressed in this thesis.

\subsection{Problem statement}

The proposed problem consists of \textbf{concurrently solving a discrete template assignment challenge and a two-dimensional packing problem}: for a given set of input articles $\articleset$, a valid solution maps each article $\articleobj{i}$ to a template $\templateobj{j} \in \templatecatalog$ and discovers a spatial configuration on $\page$ that is both feasible and of high quality.

In this context, a solution is only admissible if it satisfies the hard constraints detailed in \secref{sec:constraints_space}: every article must fit on a single page (FC~1), its assigned template must accommodate its images (FC~2) and headline (FC~3), no two articles may overlap (FC~4) or exceed the page boundaries (FC~5), and grid and gutter alignment must be guaranteed (FC~6).

Then, among feasible solutions, quality is assessed along four criteria:

\begin{itemize}
    \item \textbf{page coverage}, penalizing unallocated white space;
    \item \textbf{text capacity integrity}, penalizing mismatches between an article's length and its template's capacity;
    \item \textbf{positioning quality}, penalizing improper placement of the lead article or misaligned neighbors;
    \item \textbf{template selection editorial style}, measuring conformity with the publisher's historical template assigments through \neuralmethod\ (\secref{sec:gwes}).
\end{itemize}

These four criteria are mutually antagonistic, and coupling discrete template selection with two-dimensional packing induces a combinatorial explosion that makes exact global optimization intractable. This motivates modeling full page layout generation as a multi-objective combinatorial optimization problem, solved through a multi-objective evolutionary framework.

\subsection{Contributions}

Addressing the problem introduced above, this chapter makes two contributions, both variants of the same multi-objective evolutionary framework \methodNameGeneral\ (\secref{sec:evopagegen-approach}), which concurrently resolves template assignment and two-dimensional packing by optimizing the four  objectives formalized in \secref{sec:objective_formulation}:
\begin{itemize}
    \item \textbf{\methodNameUniform} (\secref{sec:many-objective_optimization}): a uniformly exploratory variant, based on standard NSGA-III, that autonomously covers the Pareto frontier without requiring historical design preferences.
    \item \textbf{\methodName} (\secref{sec:many-objective_optimization}): a preference-guided variant, based on Reference-Point NSGA-III (RNSGA-III), that steers the search toward reference points computed offline from historical human-designed layouts, trading exploration breadth for closer alignment with editorial practice.
\end{itemize}
Both variants share a common architecture, including a sequence-preserving backtracking packing decoder (\secref{sec:packing_engine}) that deterministically converts a chromosome-encoded template assignment and article permutation into a feasible two-dimensional page layout.
