\subsection{The print production workflow: from web articles to print pages}




\section{Motivation}

Talk about optimizing and automatingthe print production workflow. Talk briefly about my vision on how this can be automated, using AI and combinatorial optimization techniques.

Talk about the impact of this optimization and automatization on the newspaper design process, including the potential benefits for designers and editors, and the corresponding improvement in the revenues without loosing
quality of the produced pages.

Also, talk about a secondary application of this workflow that is also explored in this thesis: generation of large prints for visually impaired people. Talk about
how this can be done by using the same techniques developed for the optimization and automatization of the print production workflow.

\section{Challenges}

Talk about the difficulties of the optimization and automatization of the print production workflow, including
\begin{itemize}
    \item We are leading with layout-based elements (templates) together with multimedia (text and images), which are dificult to characterize directly without a careful understanding.
    \item The combinatorial nature of the design problem: In this case requires to select a template for each article and organize them in pages, which is a geometrically complex problem with a large number of possible combinations.
    \item The need to balance multiple objectives, such as text and image requirements, layout constraints, etc.
    \item Necesity to capture human preferences in the optimization process, to produce results that are not only optimal in terms of the objective function, but also aesthetically pleasing and aligned with the newspaper's style and brand.
    \item Verify if this process lead to the generation of large prints that are suitable for visually impaired people and also that these people prefer to read these instead of classical solutions such as magnification tools.
    \item Finally, the need to deploy these tools in a real-world setting.
\end{itemize}
